# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly. Instead, report it to the maintainer via GitHub issues or email.

## Supported Versions

Only the latest version of the repository is supported for security updates. 

## Best Practices

- This project interacts with the LeetCode GraphQL API. Ensure your local environment is secure.
- The Python scripts have been hardened to sanitize inputs and prevent path traversal.
- Never commit sensitive information or API keys (if added in the future) to this repository.
